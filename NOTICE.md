## Motion: no animation library

All interface motion uses browser features only: the Web Animations API (`element.animate`),
CSS transitions, CSS scroll-driven animations (`animation-timeline`) with an
IntersectionObserver or small scroll-handler fallback, and the View Transitions API where it
helps. 3D moments use three.js (MIT). No paid or non-MIT motion library is included or required,
so the whole template can be used, changed and sold under the MIT licence plus the licences
listed above.

## Ideas and guidance (no code copied)

- Studio-style patterns (pinned sections, horizontal work strips, image reveals, custom cursors,
  marquees) were studied in permissively licensed open-source projects, listed with stars and
  licences in the shared `RESEARCH.md` next to the templates: darkroomengineering/lenis and
  darkroomengineering/satus (MIT), arthelokyo/astrowind (MIT), themefisher/bigspring-light-nextjs
  (MIT), manulthanura/Positivus (MIT), m6v3l9/astro-theme-stone (MIT), chrhi/studio (MIT),
  xkintaro/kintarowwwards (MIT), 5araang/Nextjs-cinematic-portfolio (MIT) and
  pmndrs/react-three-next (MIT). No code, designs or assets from them are included. No
  proprietary template (for example from Wix) was copied, scraped or reverse engineered.
- Quality passes followed the written guidance of: Emil Kowalski's design engineering skills
  (https://github.com/emilkowalski/skills, MIT) for easing, durations, interruptibility and
  motion performance, and break-ui worst-case testing; Impeccable
  (https://github.com/pbakaus/impeccable, Apache-2.0) for typography, colour, spacing and polish;
  and taste-skill (https://github.com/Leonxlnx/taste-skill, MIT) for removing generic
  "generated look" tells. None of their files are included here.
